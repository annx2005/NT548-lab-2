# Yêu cầu 3 - Jenkins CI/CD cho Microservices

Thư mục này dành cho yêu cầu 3 của Lab 2.

Nội dung cần triển khai ở phần này:

- Dùng Jenkins để tự động build, test và deploy ứng dụng microservices.
- Đóng gói ứng dụng bằng Docker.
- Deploy ứng dụng lên Kubernetes.
- Tích hợp SonarQube để kiểm tra chất lượng mã nguồn.
- Có thể bổ sung Snyk hoặc Trivy để kiểm tra bảo mật.

Phần này chưa được triển khai trong bước hiện tại vì đang ưu tiên hoàn thành yêu cầu 1 trước.
